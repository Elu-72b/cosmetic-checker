# 化粧品成分チェッカー(仮)

化粧品の全成分表をカメラで撮影すると、成分ごとの**注意度(刺激リスクの目安)**を1〜5で色分け表示するWebアプリ。

## 主な機能

- 📷 **成分表の読み取り** — 撮影した画像をGemini Flash APIで解析し、成分名リストを抽出。読み取り結果は確認・修正してから解析できる
- 📝 **テキスト貼り付け入力** — 通販サイトなどの全成分表示をコピー&ペーストして解析
- 🎨 **注意度の色分け表示** — 注意度1(緑)〜5(赤)を数字つきのバッジで一覧表示。結果の上部に注意度ごとの件数を表示
- 🔢 **配合順の表示** — 全成分表示の並び順(配合量の多い順)を示し、並べ替えや目的別(保湿・防腐・香料など)の絞り込みができる
- 🔍 **成分詳細の表示** — 成分名をタップすると詳細(配合目的・説明・出典)を表示
- ⭐ **気になる成分の登録** — 登録した成分を結果画面で強調表示(端末内のみに保存・ログイン不要)
- 💾 **キャッシュ戦略** — 一度検索した成分はDBに保存し、次回以降はAPIを呼ばずに再利用

## 処理の流れ

1. ユーザーが成分表を撮影しアップロード(画像はGemini APIへの送信にのみ使い、本アプリでは保存しない)
2. Gemini APIが成分名リストを抽出し、ユーザーが内容を確認・修正
3. 各成分をDBで検索 → ヒットすれば既存データを使用、なければAPIで情報生成してDBに保存
4. 注意度に応じた色と数字で一覧表示

## 注意度について

注意度は本アプリ独自の参考指標です。判定基準は [docs/CAUTION_CRITERIA.md](docs/CAUTION_CRITERIA.md) を参照してください。

## データの出典と免責事項

- 成分の事実情報は公的・オープンなソース(旧表示指定成分リスト、EU CosIng 等)を優先して利用し、出典を明示しています
- 説明文や注意度の一部はAIにより生成されており、誤りを含む可能性があります(該当箇所には「AI生成」と表示します)
- 注意度は成分単体についての目安であり、製品全体の安全性を評価するものではありません。肌への影響には個人差があります
- 撮影画像からの成分の読み取りには誤りが生じる場合があります。必ず実際の製品表示もご確認ください
- 撮影した画像は成分抽出のため Google の Gemini API に送信されます。本アプリのサーバーには保存しません
- 本アプリの情報は参考情報であり、医学的助言ではありません。肌トラブル等が生じた場合は使用を中止し、専門医にご相談ください

## セットアップ

```bash
git clone <repository-url>
cd cosmetic-checker
docker compose build
docker compose run --rm web bin/rails db:create db:migrate db:seed
docker compose up
```

環境変数(`.env`)に `GEMINI_API_KEY` を設定してください。

## ライセンス / 出典表記

- 成分データ出典: EU CosIng(Source: European Commission)、旧表示指定成分リスト(厚生省告示)ほか
- 各成分の詳細画面に個別の出典を表示しています
