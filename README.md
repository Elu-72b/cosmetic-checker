# 化粧品成分チェッカー(仮)

化粧品の全成分表をカメラで撮影すると、成分を危険度別(1〜5)に色分け表示するWebアプリ。

## 主な機能

- 📷 **成分表の読み取り** — 撮影した画像をGemini Flash APIで解析し、成分名リストを抽出
- 🎨 **危険度の色分け表示** — 危険度1(緑)〜5(赤)のグラデーションで一覧表示
- 🔍 **成分詳細の表示** — 成分名をタップすると詳細(配合目的・説明・出典)を表示
- 💾 **キャッシュ戦略** — 一度検索した成分はDBに保存し、次回以降はAPIを呼ばずに再利用

## 技術スタック

| 分類           | 技術                                   |
| -------------- | -------------------------------------- |
| バックエンド   | Ruby on Rails 8                        |
| データベース   | PostgreSQL(pg_trgm によるあいまい検索) |
| フロントエンド | Tailwind CSS / Stimulus.js / Turbo     |
| AI・OCR        | Gemini Flash API                       |
| デプロイ       | Render                                 |

## 処理の流れ

1. ユーザーが成分表を撮影しアップロード(画像はメモリ上でのみ処理、保存しない)
2. Gemini APIが成分名リストを抽出
3. 各成分をDBで検索 → ヒットすれば既存データを使用、なければAPIで情報生成してDBに保存
4. 危険度に応じた色で一覧表示

## データの出典と免責事項

- 成分の事実情報は公的・オープンなソース(旧表示指定成分リスト、EU CosIng 等)を優先して利用し、出典を明示しています
- 説明文の一部はAIにより生成されています
- 本アプリの情報は参考情報であり、医学的助言ではありません。肌トラブル等は専門医にご相談ください

## セットアップ

```bash
git clone <repository-url>
cd cosmetic-checker
docker compose build
docker compose run --rm web bin/rails db:create db:migrate db:seed
docker compose up
```

環境変数(`.env`)に `GEMINI_API_KEY` を設定してください。

## ライセンス / 出典表記

- 成分データ出典: EU CosIng、旧表示指定成分リスト(厚生省告示)ほか
- 各成分の詳細画面に個別の出典を表示しています
