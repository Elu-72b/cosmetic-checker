# 新フェーズ開始: フェーズ $1

## あなた(Claude)がやること

1. **現在の状態を確認する**
   - `git status` で未コミットの変更がないか確認する
   - 未コミットの変更があれば、ブランチを切る前にユーザーに知らせて指示を仰ぐ
   - `git branch --show-current` で今 main にいることを確認する(mainでなければ警告する)

2. **mainを最新化する**
   - `git switch main && git pull` を実行する

3. **作業ブランチを作成する**
   - `git switch -c feature/phase$1-$2` を実行する

4. **該当フェーズの計画を読み込む**
   - `@docs/DETAILED_PLAN.md` からフェーズ $1 の「やること」と
     「🔀 ブランチとコミット計画」の表を読み取り、要約して提示する

5. **最初のコミット単位から着手する**
   - コミット計画の表の1行目から順に進める
   - 各コミットは表の「対象ファイル」に沿って行い、メッセージも表のとおりにする
   - @CLAUDE.md のGit運用ルール(schema.rb・Gemfile.lockのセット、.env非コミット)を必ず守る

## 注意

- このコマンドはブランチ作成までを行い、実装は計画に沿って1コミットずつ進める
- 各コミット前に必ず `git status` で対象ファイルを確認する
- フェーズが完了したら push → PR はユーザーに委ねる(勝手に push しない)
